Echoes Through Time is a retro-style platformer that takes you on an epic journey across five distinct historical eras. Battle era-specific enemies, defeat massive bosses, and collect temporal keys to unlock portals through time.
✨ Features

5 Unique Eras: Renaissance (1500s) → Colonial (1700s) → Industrial (1900s) → Cyber Future (2100s) → Cosmic Age (2300s)
Epic Boss Battles: Face off against The Warlord, Admiral Blackwood, The Iron Titan, Omega Prime, and the Temporal Warden
Dynamic Sound System: Procedurally generated music and sound effects using Web Audio API
Multiple Weapons: Era-specific weapons plus a bouncing tennis ball launcher
Power-Up System: Collect power-ups to become a giant titan
Parallax Backgrounds: 5-layer scrolling with atmospheric effects for each era
Responsive Controls: Keyboard, touch (mobile), and full gamepad support
